# V6.1 Setup tab

V6.1 starts from a drawing with a profile grid and no PFSUITE setup. Setup
guides the drafter through each line. The drafter places structures in plan;
PFSUITE assigns them to a line and later places their profile copies from Run.

## Layout

- One persistent **Anchor a Grid** button opens the existing blank grid dialog,
  then asks for the lower-left and top-right grid corners. It does not require
  Scan or a pre-existing stub. Its label and position do not change after the
  first grid is anchored.
- One flat list shows the anchored lines, one row per line, with utility, line
  name and Setup status. Use `metaList` for this list. Selecting a row shows
  that line's status and actions below it.
- With no anchors, the list says "No grids anchored yet." The Anchor button is
  still visible.
- The selected line's details state whether its grid is anchored, how many
  plan structures are found, and how many are assigned. The displayed assigned
  count is the current total on that line, not the number changed by the last
  command. After assigning three structures, say "3 structures assigned to
  Line 'A'." Report skipped structures separately.
- If plan structures exist but need assignment or re-assignment, show
  **Assign Structures** for the selected line. If none are found, explain that
  the drafter places the structure blocks in plan before assigning them. A line
  with its grid anchored and plan structures assigned reads **Setup complete**.
- Setup remains available for anchoring another grid after one line is ready.
  A ready line may be selected on Run; Setup does not need a Continue button.

## Selected grid actions

- **Edit Grid** opens the existing grid dialog filled with that line's current
  values. It retains the option to re-pick grid corners.
- **Delete Line** belongs inside the Edit dialog. After a confirmation that
  names the line and affected profile objects, it removes the PFSUITE anchor
  and releases profile objects on that grid. The drawn grid, centerline, plan
  structures and profile geometry remain in the drawing. Do not use the
  existing `PFREMOVE Everything` behavior for this action.
- **Zoom to Grid** moves to Run and acts on its selected line.

## Controls and commands

- Replace the Setup tree `tvwLines` and its property/value presentation with
  the flat `metaList` line list. The selected line's status is plain text, not
  another list. The file table `lvwLinkage` is not part of the main Setup view.
- Remove the Setup buttons Scan, New, Index, Remove and Zoom. Anchor a Grid
  reaches the existing blank-dialog path currently used by New. Move the
  line-specific Assign action from Run to Setup.
- Keep Run's `lvwCommand` list of structures and pipes. The selected line
  should carry between Setup and Run without a second search.
- Preserve the useful anchor checks currently run by Scan, but do not require
  the drafter to run Scan to start a line.

## Data and verification boundary

Setup status should be derived from existing anchors and plan structure
membership. The palette redesign alone does not change the CAD entity record
schema. Bump `*pf-schema*` only if implementation changes stored names or
records, with a migration path for existing drawings.

Verify the empty drawing, one ready line, multiple lines with different
statuses, a moved or newly added plan structure, Edit and Delete, and selection
carried to Run in a disposable CAD drawing. Check that Delete leaves the
drawing geometry in place and that one UNDO restores the line.
