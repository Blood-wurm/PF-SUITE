# V6.1 validation status (2026-11-21)

The V6.1 source and `pfsuiteV6_1.odcl` are work in progress on branch `v6.1`.
The original `pfsuiteV6.odcl` matches its recovery copy by SHA-256. No V6.1
change has been committed or pushed.

## Verified in AutoCAD 2027 with OpenDCL 9.3

- The V6.1 palette opens and fills Setup's line list and Run's structure rows.
- Save Settings rejects a nonnumeric slope, then saves drawing-wide slope,
  cover, and crossing clearance values in a disposable drawing.
- Without Carlson, Assign Structures now reports a warning instead of success.
- `PFSELFTEST` reported 117 passed, 0 failed in the open review drawing after
  the footer capture fix. All six Group 25 footer assertions appear as PASS
  lines in the log. Its Carlson-dependent test world was skipped.
- Delete Line on a disposable copy erased the selected anchor while leaving a
  placed object in place and marking it released. PFREFRESH left that object
  released. In a separate delete-only run, one UNDO restored the anchor and
  its 14 plan-structure memberships.
- In the same review drawing left open for the user, Delete Line on `STORM_FB`
  removed one anchor and 14 plan-structure assignments, with 10 junctions
  remaining on other lines. One subsequent `UNDO` restored the anchor,
  assignments, names, and prior object state. The reused driver log header
  incorrectly mentions two UNDO commands; this run issued one.
- A read-only inventory of that open drawing found 67 lines and no pipe or
  crossing rows. The Run list for `STORM_FB` showed 14 structure rows. The
  palette status after UNDO correctly requested that the line be selected
  again to refresh the list.
- The static LISP/OpenDCL check reported 815 defuns, 21,577 calls, 0 errors,
  and 0 warnings. `git diff --check` passed.
