# Pro-Flow exchange

`PFEXPORT` asks for a storm profile anchor and exports that line plus storm lines joined to it by a shared plan structure's membership record. It does not sweep unrelated drawing contents into the file. The output uses Pro-Flow's current `pfsuite-network` version 1 contract with `snapshot: "lines"`: each included line is a complete replacement scope on reimport.

The command refuses to write when a pipe in scope has an invalid grid or no size, or when no pipes are found. A pipe belongs to a grid only when both invert endpoints fall inside the same usable grid. The export is staged in a new UTF-8 file; replacing an existing export requires confirmation and keeps the prior file as a timestamped backup.

Rims are exported as currently recorded and are never generated by this command. The selected network export remains unverified in a live Carlson/OpenDCL drawing; it needs a CAD to Pro-Flow round trip before being called production ready.
